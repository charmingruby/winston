# Winston

An Overwatch assistant for my personal squad of friends.

## What is this?

A coach for our squad, helping us pick heroes, build compositions, and plan strategies around how we like to play.

## Available interfaces

- **MCP:** stdio server for MCP clients;
- **Agent:** HTTP server;
- **Discord:** bot that responds to mentions and replies to its messages in a server, using the replied-to response as context;
